# Laravel Shop — Docker Environment

Этот проект представляет собой интернет-магазин на базе Laravel 13, полностью настроенный для работы в изолированной среде Docker.

## Особенности сборки
* **PHP 8.4-fpm**: Версия обновлена для полной совместимости с последними функциями Laravel и исправления ошибок рефлексии.
* **Собственный Dockerfile**: Включает предустановленные расширения `pdo_mysql`, `mbstring` и необходимые системные библиотеки для работы с БД.
* **MariaDB 10.11**: Используется в качестве основной базы данных.
* **Nginx**: Оптимизированный веб-сервер для обработки запросов к приложению.
